# EarnPro - Tasks, Games & Rewards Application

Complete source code and assets for EarnPro.

## 🚀 How to Run & Use (Sabhi Tarike):

### Tarika 1: Direct Run (Bina Kisi Server Ke - Sabse Aasan)
1. Is folder me `index.html` file par **Double-Click** karke kisi bhi browser (Chrome, Edge, Firefox, Brave) me open karein.
2. Sabhi features, Lucky Spin, Daily Tasks, 5-Digit Code Verification, Arrow Puzzle, Wallet, aur Admin Panel direct chalenge!

### Tarika 2: Node.js / VS Code Live Server
Agar aap Node.js ya VS Code use karte hain:
```bash
npm install
npm run dev
# ya
npm start
```
Browser me `http://localhost:3000` open karein.

### Tarika 3: Web Hosting / Android App (WebView / Capacitor)
- Is poore folder ko kisi bhi hosting (cPanel, Hostinger, GitHub Pages, Netlify, Vercel) par upload karein.
- Ya Android Studio me `assets/www` me copy karein — sabhi paths relative hain aur bina kisi configuration ke turant chalenge.

## 📁 File Structure:
- `index.html` - Complete UI, Navigation, Modals, Games & Styling
- `src/app.js` & `app.js` - Complete Firebase Realtime Database & Verification Logic
- `manifest.json` & `sw.js` - Progressive Web App (PWA) Offline & Installation Support
- `icon-192.png` & `icon-512.png` - App Icons
